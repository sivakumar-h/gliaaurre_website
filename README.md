# GliaAurre Production Website

Production-grade website for **GliaAurre** — Engineering the Future of Clarity from Signal to Silicon.

Built with **Next.js 14+ (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Quick Start Guide (How to Run)

### 1. Prerequisites
Make sure **Node.js (v18 or higher)** is installed on your computer:
- Download from: https://nodejs.org (LTS recommended)
- Verify in terminal:
  ```bash
  node -v
  npm -v
  ```

---

### 2. Extract and Open the Project
1. Extract `GliaAurre-Website-Production.zip` to a folder of your choice.
2. Open your terminal (PowerShell, Command Prompt, or Terminal) and navigate to the project directory:
   ```bash
   cd path/to/extracted/folder
   ```

---

### 3. Install Dependencies
Run the following command:
```bash
npm install
```

---

### 4. Start the Local Server
Start the development server:
```bash
npm run dev
```

---

### 5. View the Website
Open your browser and navigate to:
```
http://localhost:3000
```

---

## 📄 Website Pages & Features

| Route | Page | Key Highlights |
| :--- | :--- | :--- |
| `/` | **Home** | Tagline *"Engineering the Future of Clarity"*, live interactive acoustic wave canvas, split-layout mission section, philosophy preview. |
| `/about` | **About** | *Who We Are*, *What Drives Us*, *How We Think*, *Our Approach*, plus interactive 5-layer co-design stack explorer. |
| `/why-us` | **Why Us** | 5 core engineering pillars and the full-stack paradigm comparison matrix. |
| `/careers` | **Careers** | *"Great engineering doesn't shout. It speaks for itself."* manifesto, filterable engineering openings, expandable job cards, and interactive application modal with resume upload (PDF/DOC). |
| `/contact` | **Contact** | Secure inquiry form with classification and direct email routing. |
